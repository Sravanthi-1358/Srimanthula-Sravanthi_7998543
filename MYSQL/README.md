# 📊 Event Management SQL Project

## 📌 Overview
This project is a complete **Event Management System database** built using MySQL.  
It demonstrates database design, relationships, sample data, and **25 real-world SQL queries** used for analytics and reporting.

---

## 🗄️ Database Schema

The project contains 6 main tables:

- **Users** → stores user information  
- **Events** → event details and organizers  
- **Sessions** → sessions under each event  
- **Registrations** → user event registrations  
- **Feedback** → user feedback and ratings  
- **Resources** → event-related resources (PDF, images, links)

---

## 🧠 Key SQL Concepts Used

This project covers important SQL concepts:

- SELECT, WHERE, ORDER BY  
- JOINs (INNER, LEFT, SELF JOIN)  
- GROUP BY & HAVING  
- Aggregate functions (COUNT, AVG)  
- Subqueries  
- EXISTS / NOT EXISTS  
- Date functions (DATE_SUB, DATE_FORMAT, TIMESTAMPDIFF)  
- Data analysis queries

---
